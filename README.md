# Домашнє завдання з базових алгоритмів до теми 5.


## Порівняння ефективності алгоритмів пошуку підрядка – 3 завдання.

### Опис проєкту
Цей проєкт порівнює швидкодію трьох алгоритмів пошуку підрядка у тексті:
1. **Boyer–Moore** (з евристикою “поганого символу”).
2. **Knuth–Morris–Pratt (KMP)**.
3. **Rabin–Karp** (ролінговий хеш).

Порівняння виконується на двох текстових файлах:
- **стаття 1.txt**
- **стаття 2.txt**

Файли статей знаходяться у цій же директорії, їх можна відкрити й переглянути вручну.

---

### Як працює код
1. Скрипт зчитує два тексти зі файлів **стаття 1.txt** та **стаття 2.txt**.
2. Для кожного тексту задаються два підрядки:
   - **наявний підрядок** (існує у тексті);
   - **вигаданий підрядок** (відсутній у тексті).
3. Для кожної пари (текст, підрядок) запускаються всі три алгоритми.
4. Час виконання вимірюється через `timeit` з кількістю повторів **100**.
5. Результати записуються у файл:
   - **substring_search_results.md**
6. Додатково у консоль виводиться короткий підсумок щодо найшвидших алгоритмів.

---

### Використані підрядки
Для **статті 1**:
- existing: **"жадібний алгоритм"**

Для **статті 2**:

### Як порівняти інші підрядки
Щоб протестувати інші шаблони, достатньо змінити ці змінні у блоці `__main__`:

```python
existing_pattern_1 = "..."
missing_pattern_1 = "..."
existing_pattern_2 = "..."
missing_pattern_2 = "..."
```

Після запуску скрипта звіт з новими вимірюваннями буде згенерований автоматично.

### Підсумкові результати

За отриманими вимірюваннями для обох стайте найшвидший алгоритм – Boyer–Moore.

Це пояснюється тим, що Boyer–Moore:
– порівнює символи з кінця шаблону;
– у разі невідповідності робить великі зсуви завдяки евристиці “поганого символу”;
– особливо ефективний, коли підрядка немає у тексті (негативний пошук).

KMP і Rabin–Karp працюють зі складністю O(n) у гіршому й типовому випадках, але:
– KMP перевіряє текст послідовно, не “перестрибуючи” ділянки;
– Rabin–Karp має додаткові витрати на хешування й перевірки після збігу хешів.

Таким чином, на вибраних статтях та підрядках Boyer–Moore демонструє сталі переваги.
